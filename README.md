# JPD Order Documents Email · 1.0.1

Αυτόνομο plugin WooCommerce. Δεν απαιτεί το plugin λιστών B2B Matrix και δεν το αλλάζει.

## Source και build

Το repository περιέχει τον PHP/JavaScript/CSS κώδικα, τα tests και ολόκληρο τον απομονωμένο κώδικα των βιβλιοθηκών PDF. Δεν χρειάζεται npm ή Composer για να χτίσετε το plugin. Απαιτείται Python 3.9+ μόνο για τη συσκευασία:

```sh
git clone https://github.com/JPDdesigners/jpd-order-documents.git
cd jpd-order-documents
python tools/build_release.py
```

Το έτοιμο αρχείο είναι `releases/jpd-order-documents-1.0.1.zip`, με έναν φάκελο `jpd-order-documents/` στη ρίζα. Το script ελέγχει το περιεχόμενο κάθε αρχείου στο ZIP και αποκλείει tests, εργαλεία ανάπτυξης και τοπικά αρχεία. Χρησιμοποιήστε `--force` για αντικατάσταση υπάρχοντος ZIP. Για εγκατάσταση WordPress χρησιμοποιήστε αυτό το ZIP ή το αντίστοιχο asset από GitHub Releases, όχι το αυτόματο GitHub source archive.

Ο δικός μας κώδικας διατίθεται με GPL-2.0-or-later· δείτε [LICENSE](LICENSE). Οι βιβλιοθήκες και οι γραμματοσειρές διατηρούν τις άδειες και αναφορές τους μέσα στο `lib/`.

Για έλεγχο με PHP 7.4+ και DOM/mbstring/zlib:

```sh
php tests/backend.php
php tests/pdf.php 1000
php -S 127.0.0.1:8093 tests/router.php
```

Το τελευταίο είναι αποκλειστικά τοπική προεπισκόπηση με mock παραγγελίες και χωρίς πραγματική αποστολή email. Δείτε [TESTING.md](TESTING.md) για κάλυψη και περιορισμούς και [tools/README.md](tools/README.md) για προετοιμασία των upstream βιβλιοθηκών. Οι αλλαγές στα απλά PHP/JS/CSS αρχεία δεν απαιτούν μεταγλώττιση: τρέχετε ξανά το script συσκευασίας.

## Εγκατάσταση και χρήση

1. Ανεβάστε το `jpd-order-documents-1.0.1.zip` από Πρόσθετα → Νέο πρόσθετο → Μεταφόρτωση. Ενεργοποιήστε το με ενεργό WooCommerce. Αν υπάρχει η 1.0.0, επιλέξτε αντικατάσταση της εγκατεστημένης έκδοσης.
2. Το υπάρχον snippet `JPD B2B PRINT / PDF / CSV v2.2` παραμένει όπως είναι. Αν είναι ενεργό, χρησιμοποιείται η δική του `collect()` για ίδιους υπολογισμούς. Αν δεν υπάρχει, το plugin περιέχει τον ίδιο συλλέκτη δεδομένων.
3. Ως χρήστης με `manage_woocommerce`, ανοίξτε την «Αποστολή εγγράφων» από My Account → Παραγγελίες ή τις παραγγελίες διαχείρισης WooCommerce. Λειτουργεί επίσης μετά από User Switching του John Blackbourn σε λογαριασμό πελάτη: επαληθεύονται και τα δύο cookies του αρχικού χρήστη και η παραγγελία πρέπει να ανήκει στον τρέχοντα πελάτη.
4. Το **Συνοπτικό PDF** είναι αρχικά επιλεγμένο. Το **CSV για Excel** επιλέγεται προαιρετικά. Δεν επισυνάπτεται PDF με φωτογραφίες.
5. Πατήστε «Δημιουργία εγγράφων». Όταν ολοκληρωθούν όλα, εμφανίζεται το μέγεθος. Πατήστε «Αποστολή email» για αποστολή στο email χρέωσης της παραγγελίας.
6. Ρυθμίσεις → WooCommerce → Emails → «JPD · Έγγραφα παραγγελίας»: ενεργοποίηση, θέμα, επικεφαλίδα και πρόσθετο κείμενο. Χρησιμοποιούνται ο αποστολέας, το βασικό HTML branding και η εγκατεστημένη διαδρομή email/SMTP του WooCommerce. Δεν περιλαμβάνεται ο μεγάλος πίνακας προϊόντων στο σώμα του email.

Αυτό είναι πρόσθετο, χειροκίνητο email. Το συνηθισμένο email `processing` συνεχίζει να λειτουργεί ανεξάρτητα. Δεν αλλάζει η κατάσταση παραγγελίας.

Από την 1.0.1, το αιωρούμενο «Switch back» του User Switching στο κάτω μέρος του frontend απενεργοποιείται σε όλο το site μέσω του επίσημου φίλτρου `user_switching_in_footer`. Η επιστροφή στον λογαριασμό πωλητή από το μενού My Account παραμένει διαθέσιμη. Δεν απαιτείται CSS και δεν αλλάζουν τα cookies, η διάρκεια σύνδεσης ή τα δικαιώματα χρηστών.

Απαιτούνται PHP 7.4+ και οι επεκτάσεις DOM, mbstring, zlib. Δεν απαιτείται GD, επειδή το συνοπτικό PDF δεν περιέχει εικόνες. Η αποστολή πρέπει να γίνεται σύγχρονα μέσω WooCommerce/wp_mail/SMTP, ώστε τα συνημμένα να έχουν διαβαστεί πριν διαγραφούν· εξωτερικό plugin που βάζει και το `wp_mail` σε δική του ουρά χρειάζεται να εξαιρεί αυτό το email.

## Τι περιλαμβάνουν τα έγγραφα

- Ποσότητες παραγγελίας, **τρέχουσες** τιμές και χαρακτηριστικά προϊόντων κατά την έναρξη δημιουργίας. Μία κοινή συλλογή δεδομένων για PDF και CSV, ώστε να συμφωνούν μεταξύ τους.
- Οι ίδιες κατηγορίες, ομαδοποίηση προϊόντος/χρώματος, μεγέθη, σύνολα, σημειώσεις και fallback αποθηκευμένης αξίας γραμμής που χρησιμοποιεί το δοσμένο snippet.
- Τα φίλτρα `jpd_b2b_export_include_item` και `jpd_b2b_export_unit_price` εξακολουθούν να εφαρμόζονται. Δεν προστίθεται νέος κανόνας ακύρωσης γραμμών.
- Το PDF δημιουργείται πραγματικά στον server με ενσωματωμένο Dompdf 3.1.6 και ελληνική γραμματοσειρά DejaVu Sans. Η διάταξη έχει προσαρμοστεί για PDF· η προηγούμενη HTML εκτύπωση του snippet δεν αλλάζει. Στην επικεφαλίδα εμφανίζεται το όνομα του site, όχι το SVG logo της εκτύπωσης.
- Το CSV είναι UTF-8 με BOM, ελληνικό δεκαδικό κόμμα, διαχωριστικό `;` και προστασία τύπων στα κειμενικά πεδία. Είναι CSV, όχι XLSX.
- Η ροή αυτή προορίζεται για τις προπαραγγελίες σας χωρίς φόρους, μεταφορικά ή κουπόνια. Δεν παρουσιάζει πλήρες φορολογικό σύνολο checkout.

## Προσωρινά αρχεία και αποτυχίες

Δεν υπάρχει μόνιμο αρχείο εγγράφων, Action Scheduler, WP-Cron ή server cron. Τα αρχεία τοποθετούνται σε ιδιωτικό υποφάκελο του προσωρινού φακέλου PHP **έξω από τον δημόσιο φάκελο του site**, με τυχαίο token και δικαιώματα 0700/0600. Δεν υπάρχει δημόσιο URL λήψης.

Μετά το αποτέλεσμα αποστολής ή την ακύρωση τα έγγραφα διαγράφονται. Μένει μόνο μια προσωρινή εγγραφή προόδου/αποτελέσματος, χωρίς τα δεδομένα προϊόντων, για προστασία από επανάληψη του ίδιου αιτήματος. Η συνεδρία ισχύει για 30 λεπτά. Εγκαταλελειμμένα αρχεία καθαρίζονται **στην επόμενη χρήση του plugin** μετά τη λήξη· χωρίς scheduler δεν υποσχόμαστε διαγραφή ακριβώς στο 30ό λεπτό. Η απεγκατάσταση καθαρίζει τους αδρανείς ιδιωτικούς φακέλους και τις ρυθμίσεις αυτού του plugin.

Το browser εκκινεί ένα αίτημα ανά έγγραφο και κατόπιν ένα για email. Κρατήστε τη σελίδα ανοιχτή. Το PDF παράγεται σε ένα αίτημα, εσωτερικά σε τμήματα έως 60 ομάδων προϊόντος/χρώματος, που ενώνονται σε **ένα** συνημμένο. Έτσι μειώνεται η μνήμη του HTML layout engine. Δεν υπάρχουν cron jobs ή ανακριβείς εκτιμήσεις ποσοστού. Η μπάρα του τρέχοντος βήματος είναι αόριστη όσο εκτελείται· μετά δείχνει πόσα έγγραφα ολοκληρώθηκαν. Ιδιαίτερα μεγάλες παραγγελίες εξακολουθούν να εξαρτώνται από τα όρια PHP μνήμης/χρόνου του hosting.

Διπλό πάτημα δεν επαναλαμβάνει αποστολή για το ίδιο token. Σε αβέβαιο αποτέλεσμα/χαμένη σύνδεση υπάρχει «Έλεγχος προόδου», χωρίς αυτόματη επανάληψη email. Ελέγξτε SMTP πριν επιλέξετε συνειδητά νέα δημιουργία και αποστολή. Η αποδοχή από το σύστημα email δεν επιβεβαιώνει παράδοση στο γραμματοκιβώτιο. Καταγράφεται σημείωση παραγγελίας όταν το σύστημα αποδέχεται την αποστολή.

Αν αλλάξει η παραγγελία κατά τη δημιουργία, η αποστολή μπλοκάρεται και χρειάζεται νέα δημιουργία. Επόμενη ανεξάρτητη δημιουργία χρησιμοποιεί ξανά τις τότε τρέχουσες τιμές.

## Όριο μεγέθους

Αρχικό όριο συνολικών συνημμένων: **20 MiB**, με έλεγχο πριν από την αποστολή. Προσαρμόζεται με `jpd_od_max_attachment_bytes` βάσει του πραγματικού SMTP provider. Το MIME/base64 αυξάνει το συνολικό μέγεθος email· η υπηρεσία σας μπορεί να έχει μικρότερο όριο ολόκληρου μηνύματος. Το Hostinger Mail αναφέρει όριο εξερχόμενων συνημμένων 25 MB, ενώ τα πακέτα cPanel αναφέρουν όριο ολόκληρου μηνύματος 20 MB. Αν χρησιμοποιείτε τέτοιο provider, μειώστε το όριο αντίστοιχα. Μην το αυξήσετε επειδή έχετε περισσότερο χώρο στον δίσκο.

## Βιβλιοθήκες

Οι εξαρτήσεις PDF περιλαμβάνονται στο ZIP, δεν χρειάζεται Composer στο hosting. Τα namespaces Dompdf, FontLib, Svg, Masterminds, Sabberworm, FPDI και FPDF έχουν απομονωθεί κάτω από `JPD_Order_Documents_Vendor`. Για τη συνένωση χρησιμοποιούνται FPDI 2.6.8 και FPDF 1.9.0. Τα αρχεία αδειών παραμένουν στο `lib/`. Χρησιμοποιείται αποκλειστικά ο εσωτερικός loader και δεν φορτώνεται το Composer autoloader του πακέτου.

## Έλεγχος στο site

Δοκιμάστε πρώτα μικρή δική σας παραγγελία: PDF μόνο, PDF+CSV, User Switching, πραγματική παραλαβή email και μεγάλο συνοπτικό PDF. Ελέγξτε subject/branding και WooCommerce → Κατάσταση → Καταγραφές (`jpd-order-documents`) σε σφάλμα. Δεν πραγματοποιήθηκε δοκιμαστική αποστολή στο ζωντανό site κατά την ανάπτυξη.
